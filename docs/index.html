Illustrative policy · UDP/53

A SYSTEM IS COMPROMISED

An attacker has gained access to an internal system and wants to steal its secrets. Email and uploads could be flagged and blocked, so they turn to DNS.

DNS normally looks up website addresses. AlphaGen hides secret in the query names, one character at a time. Wireshark records the requests sent to the attacker’s server.

Here, the firewall checks addresses and ports but doesn’t inspect the DNS query names. The hidden data passes through unnoticed.

The queries reach the attacker’s server, where AlphaRes reconstructs secret. The secret has successfully been transmitted outside the internal network.

Now DNS requests can only go to approved servers. The attacker’s server at 203.0.113.20 isn’t on the list, so this transfer is stopped.

FEATURED / SECURITY ENGINEERINGOCT 2022 — MAR 2023

AlphaReGen

Generate traffic. Configure the firewall. Inspect the evidence.

AlphaReGen pairs a Python command-line traffic generator, AlphaGen, with a responder, AlphaRes, in a segmented VMware lab. Students generate normal and malicious traffic, configure firewall policies, and compare firewall logs and Wireshark captures with what reaches the responder.

I led the five-person team and built the shared framework for protocol selection, input validation and generator–responder coordination.

Used beyond the final-year project. AlphaReGen v1 was integrated into Singapore Polytechnic’s Cybersecurity Infrastructure Configuration module. On SP’s page: Year 2 → Cyber Defence Security.

Network testbed and firewall policy

Inside, Outside and DMZ zones separate the network. A cloud simulator handles routing and NAT. Our team configured and tested Palo Alto and pfSense firewalls, and delivered reusable configurations and an administration guide.

Shared protocol framework

Protocol modules share menus, input validation, learner explanations and Wireshark filters. AlphaGen selects the exercise; AlphaRes runs the matching service.

Python / Scapy / VMware / pfSense / Palo Alto / Wireshark
