							FEATURED / SECURITY ENGINEERINGOCT 2022 — MAR 2023
						

						
AlphaReGen

						
Generate traffic. Configure the firewall. Inspect the evidence.

						

							AlphaReGen pairs a Python command-line traffic generator, AlphaGen, with
							a responder, AlphaRes, in a segmented VMware lab. Students generate normal
							and malicious traffic, configure firewall policies, and compare firewall
							logs and Wireshark captures with what reaches the responder.
						

						

							I led the five-person team and built the shared framework for protocol
							selection, input validation and generator–responder coordination.
						

						

							Used beyond the final-year project. AlphaReGen v1 was
							integrated into Singapore Polytechnic’s
							Cybersecurity Infrastructure Configuration module.
							On SP’s page: Year 2 → Cyber Defence Security.
						

						

							

								
Network testbed and firewall policy

								

									Inside, Outside and DMZ zones separate the network. A cloud simulator
									handles routing and NAT. Our team configured and tested Palo Alto and
									pfSense firewalls, and delivered reusable configurations and an
									administration guide.
								

							

							

								
Shared protocol framework

								

									Protocol modules share menus, input validation, learner explanations
									and Wireshark filters. AlphaGen selects the exercise; AlphaRes runs
									the matching service.
