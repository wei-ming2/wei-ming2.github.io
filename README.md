# Foo Wei Ming — Personal Portfolio
 
My personal site: projects, experience, thoughts and résumé in one place. It is plain HTML, CSS and JavaScript with no framework, no dependencies and no build step, so the whole thing is short enough to read end to end.
 
**Live site:** [wei-ming2.github.io](https://wei-ming2.github.io)

## Highlights
 
- **Interactive project demos instead of screenshots.**
  - **AlphaReGen** is a step-by-step walkthrough of a DNS exfiltration experiment. You follow a credential hidden in DNS queries, then switch between a *Baseline* and a *Restricted DNS* firewall policy to see what the firewall logs and the collector receive.
  - **This Site** includes a mini preview of the portfolio that you can resize between 375px, 768px and 1440px.
- **A résumé that updates itself.** A scheduled GitHub Actions workflow rebuilds it from Overleaf every month (see [Résumé sync](#résumé-sync)).
- **Thoughts written in Markdown.** Each piece is a `.md` file with a small front-matter block, loaded in the browser at runtime, so there is no CMS or build step.

## Run it locally
 
```sh
python3 -m http.server 4173 --directory docs
```
 
Then open <http://localhost:4173>. A local server is needed because the Thoughts are loaded with `fetch()`, which browsers block on `file://` URLs.
 
## Deployment
 
The site is served by GitHub Pages straight from the `main` branch's `/docs` folder, with no build step. Because the repository is named `wei-ming2.github.io`, it lives at the root of that domain.
 
## Résumé sync
 
My résumé is written in LaTeX on Overleaf. [`sync_resume.yml`](.github/workflows/sync_resume.yml) keeps the copy on this site current, running on the 1st of every month at 8:00 am Singapore time, or on demand from the Actions tab.
 
1. Downloads `resume.tex` from Overleaf using [overleaf-resume-syncer](https://github.com/Sbrjt/overleaf-resume-syncer). The share link is stored as a repository secret.
2. Strips my phone number from the LaTeX source, so it never reaches the public repo.
3. Compiles the cleaned source with Tectonic.
4. Exports a PDF and a 300 DPI PNG into `docs/images/`.
5. Commits only if the rendered PNG changed. The PDF is left out of that check because its metadata (such as the date) changes on every build.
## Design notes
 
The design started in [Stitch](https://stitch.withgoogle.com/), was implemented with Codex's help, and was reviewed and tuned by hand. The look is a warm neutral background with charcoal text and a clay accent.
